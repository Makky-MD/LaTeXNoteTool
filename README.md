# LaTeXNoteTool 轻量化 LaTeX 编译软件 使用说明书

## 一、软件简介

本软件为**免配置、免 Python、免本地 LaTeX 环境**独立 Windows 桌面工具，内置轻量化 TinyTeX 编译内核，支持 LaTeX 中文笔记、数学公式、定理代码一键编译 PDF；自带代码编辑器、自动清理缓存、编译完成自动弹窗打开 PDF、外部 TeX 文件导入功能，零门槛上手。

## 二、软件打包目录说明

### 最终分发完整文件夹（请勿删改、移动内部文件）

```plaintext
LaTeXTool/
├─ LaTeXNoteTool.exe   # 主启动程序（带内置图标）
├─ main.tex            # 默认空白笔记模板文件
└─ TinyTeX/            # 内置编译内核【绝对禁止删除/改名/移动】
```

✅ 可删除：打包残留 build、dist、源码、图标文件（分发前已清理完毕）

❌ 禁止操作：修改 TinyTeX 文件夹名称、移动内核、中文路径存放软件

## 三、系统使用前置要求

1. 仅支持 **Windows10/Windows11** 系统，不支持 Mac、平板、手机

2. 软件

   整个文件夹存放路径不能含中文、空格、特殊符号
   ✅ 正确示例：
   ```
   D:\Software\LaTeXTool
   ```
   ❌ 错误示例：

   ```
   桌面\笔记软件\LaTeXTool
   ```
   ```
   D:\工具\LaTeX笔记
   ```
3. 无需安装任何运行库、无需联网、无需配置环境，解压即用

## 四、软件五大功能按钮详解

### 1. 打开 TEX 文件

无需手动复制粘贴代码！

- 支持直接打开电脑本地任意`.tex`笔记文件、大型 TeX 源码文件
- 自动载入代码至编辑器，自动绑定对应文件，独立生成对应 PDF
- 支持上千行超大笔记、长篇论文源码，无需拆分粘贴

### 2. 编译生成 PDF

1. 编辑代码完成后点击按钮
2. 自动清理历史临时缓存文件→后台静默编译→自动生成 PDF
3. **编译完成自动弹窗打开 PDF 文件**，无需手动查找
4. 默认编译超时：3 分钟，适配超大体积笔记、海量数学公式文档

### 3. 清理临时文件

一键清除编译残留`.aux/.log/.toc`垃圾缓存，保持文件夹整洁；编译失败、文件错乱时点击修复文件冲突。

### 4. 打开 PDF

手动调取当前编译完成的 PDF 文档，快速预览、打印、保存。

### 5. 内置代码编辑区

自带代码编辑框，支持直接手写 LaTeX 代码、修改导入代码，字体清晰、代码不卡顿。

## 五、两种使用方式

### 方式一：新建笔记

1. 双击`LaTeXNoteTool.exe`启动软件
2. 编辑区直接粘贴 / 手写 LaTeX 笔记代码
3. 点击【编译生成 PDF】，自动出文件 + 自动打开 PDF
4. 文件自动保存至目录`main.tex`，下次打开自动加载

### 方式二：打开已有大型 TeX 文件（大笔记 / 现成源码）

1. 点击【打开 TEX 文件】
2. 选中电脑内任意保存好的 LaTeX 大文件、长篇笔记源码
3. 软件自动加载、自动绑定文件，直接编译
4. 独立生成同名 PDF，互不干扰，**超大文件不卡顿、不强制复制代码**

## 六、关于大文件 & 编译超时解答

1. 上千行公式、整本专业课笔记、大型论文：**无需拆分代码、无需复制粘贴**，直接导入原文件即可
2. 软件已优化超时时间，常规课程笔记、数学公式文档**绝不会超时**
3. 极端超大型文档自动超时，软件弹窗提示，不会卡死软件、不会闪退

## 七、常见问题 FAQ

### Q1：打开软件报错找不到内核？

A：移动 / 删除了 TinyTeX 文件夹，还原文件位置即可。

### Q2：编译卡住、编译失败？

A：①代码语法错误 ②软件放在中文文件夹路径 ③网络无关，本地离线编译。

### Q3：需要每次复制代码到 main.tex 吗？

A：不需要！使用【打开 TEX 文件】功能，直接读取本地文件，告别手动复制。

### Q4：文件夹一堆多余文件怎么办？

A：软件**编译后自动清理所有垃圾缓存**，仅保留 exe、源码、PDF、内核文件夹，界面干净。

### Q5：软件可以改名吗？

A：exe 程序建议保留英文原名`LaTeXNoteTool.exe`，图标永久正常不消失。

# Coze扣子智能体重建教程
## 智能体说明
本智能体用于自动生成、优化LaTeX笔记工具代码，适配公式文档编译需求，基于字节Seed大模型，搭建于Coze扣子平台。
仓库仅存放提示词与笔记模板文档，无平台加密工程包，需手动在扣子平台重建。

## 重建步骤
1. 打开Coze扣子官网，登录账号，新建空白智能体；
2. 打开 `agent_prompt.md`，全选复制全部内容，粘贴到智能体「系统提示词」框；
3. 保存发布，即可得到和原版完全一致的智能体。
